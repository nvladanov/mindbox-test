## Исправленные ошибки

### 1. Модальное окно не открывалось

- Исправлено некорректное обновление состояния в методе `toggle`
- Было: прямая мутация состояния `(this.state as any).opened = opened`
- Стало: корректное обновление через `setState({ opened })`

### 2. Некорректная работа с массивом инвайтов

- Исправлено мутирование массива через `push`
- Было: `invites.push(name)`
- Стало: создание нового массива через spread оператор `[...invites, name]`
